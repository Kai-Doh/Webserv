9. Per-server body size limit (413)

  
The second server{} block (port 8081, a genuinely different site)
    sets client_max_body_size 10. Cross-origin from this page, so use curl:

  curl -i -X POST --data "this is more than ten bytes" http://127.0.0.1:8081/
# expect: 413 Payload Too Large

curl -i -X POST --data "short" http://127.0.0.1:8081/
# expect: 201 Created (5 bytes, within the 10-byte limit, upload_store configured there)

  
10. Unknown method / malformed request (no crash)

  

    
  

  

  
For a truly malformed request line, use raw sockets:
    printf 'GARBAGE\r\n\r\n' | nc 127.0.0.1 8080 → 400 Bad Request, server keeps running.


  
11. HTTP status code coverage

  
The eval sheet asks to verify every status code returned is accurate. This checks
    every code this server produces, beyond what's already exercised above (200/201/204/301/404/405 in
    sections 1–8). Codes not listed here (303, 307, 408, 409, 411, 501) are defined but never
    produced by any current code path.
