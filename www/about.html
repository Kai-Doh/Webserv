About this project

The HTTP + CGI half of a two-person 42 Webserv project: request parsing, routing, and CGI execution, written in C++98.

This page is one of two static files served straight from disk by the server itself — no template engine, no build step. The rest of the site (the homepage, the contact form, the file upload widget) all route through the same request pipeline you'd hit with curl or a raw socket.

Under the hood, a single non-blocking poll() loop watches every client connection and every CGI pipe at once. Static files are read straight off disk; anything with a configured CGI extension is forked, executed, and its output streamed back — all without ever blocking the rest of the server.

This particular route only answers GET requests — try a DELETE against it from the diagnostics page to see the 405 response and its Allow header.
