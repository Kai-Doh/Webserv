A web server, held together by one poll() loop.

Webserv is a non-blocking HTTP/1.1 server written from scratch in C++98 — static files, CGI, uploads and config-driven routing, all multiplexed through a single event loop, no threads.

Under the hood

What it does

Every one of these runs through the exact same request pipeline this site is served from.

⟳

Single-poll concurrency

Every client socket and every CGI pipe is driven by one poll() call. No thread per client, no blocking read or write, ever.

⚙

CGI out of the box

Executes Python, PHP-CGI, or any interpreter you configure — full RFC 3875 environment, chunked request un-chunking, and PATH_INFO support.

🗺

Config-driven routing

nginx-style server{} / location{} blocks: per-route methods, redirects, custom document roots, upload targets.

⇅

Uploads & static files

Serves a fully static site and accepts client uploads, through the same non-blocking request/response cycle.
